Vector Space Operations

Add vectors, measure their length, and compare their directions.

About this module

What it is: A vector is just a list of numbers, like (3, 4). You can picture it as an arrow with a direction and a length.

Why machine learning cares: ML turns everything (a house, a photo, a sentence) into a vector of numbers. Comparing two vectors tells a model how similar two things are.

How to use it: Enter two vectors with the same number of values, separated by commas (for example 1, 2, 3). The program adds them, measures their lengths, and computes cosine similarity, a score from -1 to 1 for how closely they point the same way.
