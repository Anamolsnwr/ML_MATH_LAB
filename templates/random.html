Random Sampling Engine

Generate random numbers between a minimum and a maximum.

About this module

What it is: This module draws random numbers from a range you choose. Every value in the range is equally likely, like a fair spinner (this is called a uniform distribution).

Why machine learning cares: Randomness is everywhere in ML: shuffling data before training, picking small random batches, and giving a model its random starting weights.

How to use it: Choose how many numbers you want and the smallest and largest value allowed. Press Run and you get that many random numbers.
