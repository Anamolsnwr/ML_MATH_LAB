About this module

What it is: An identity matrix is a square grid of numbers where the diagonal (top-left to bottom-right) is all 1s and every other cell is 0. It is the "do nothing" matrix: multiplying by it leaves things unchanged, like multiplying a number by 1.

Why machine learning cares: Matrices are how ML stores data and model weights. The identity matrix is the neutral starting point used in many matrix calculations and in setting up neural network layers.

How to use it: Enter a size (for example 4) and press Run. The program builds a 4×4 identity matrix and explains what you see.
